# Kairn

Kairn gère vos comptes Minecraft Java (Microsoft ou cracked) et les fait jouer depuis votre PC :
dizaines de bots connectés, kits récupérés tout seuls, scripts, chaînes d'actions, enregistrements
rejoués, et vous pouvez jouer vous-même avec n'importe lequel de vos comptes.

**[📘 Guide d'utilisation](https://kairnmc.github.io/kairn-releases/)** ·
**[⬇️ Télécharger la dernière version](https://github.com/kairnmc/kairn-releases/releases/latest)**

## Installer

1. Téléchargez `Kairn-Setup-x.y.z.exe` dans la [dernière version](https://github.com/kairnmc/kairn-releases/releases/latest)
   (Windows 10 ou 11, 64 bits).
2. Lancez-le. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur
   **Informations complémentaires**, puis **Exécuter quand même**.
3. Kairn se met ensuite à jour tout seul.

## Accès

Kairn s'utilise avec un **code d'accès personnel**, valable sur un seul PC : au premier lancement,
envoyez l'identifiant de votre PC affiché par Kairn à son auteur, qui vous renvoie votre code.
Voir [Activer Kairn](https://kairnmc.github.io/kairn-releases/#activer-kairn).

## Ce dépôt

Il contient les installateurs, publiés dans les [versions](https://github.com/kairnmc/kairn-releases/releases),
le [guide](https://kairnmc.github.io/kairn-releases/), et des fichiers signés que Kairn lit tout seul
(la liste des accès, le catalogue des plugins officiels) : il n'y a rien à y modifier.
