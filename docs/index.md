# Kairn

Kairn gère vos comptes Minecraft Java (Microsoft ou cracked) et les fait jouer depuis votre PC :
connexion de dizaines de bots, récupération des kits, scripts, chaînes d'actions, enregistrements
rejoués, et même jouer vous-même avec n'importe lequel de vos comptes.

## Installer

1. Téléchargez le dernier installateur : [Kairn Setup](https://github.com/kairnmc/kairn-releases/releases/latest)
   (fichier `Kairn Setup x.y.z.exe`).
2. Lancez-le. Windows affiche peut-être « Windows a protégé votre ordinateur » : cliquez sur
   **Informations complémentaires**, puis **Exécuter quand même**. L'installateur n'est pas encore
   signé ; les mises à jour suivantes s'installent sans cet avertissement.
3. Kairn s'ouvre et s'installe dans votre session Windows (pas besoin de droits administrateur).

Kairn se met ensuite à jour tout seul : voir [Mises à jour](parametres.html#mises-à-jour).

## Activer Kairn

Kairn s'utilise avec un **code d'accès personnel**, valable sur un seul PC.

1. Au premier lancement, l'écran **Activer Kairn** affiche l'**identifiant de ce PC**
   (6 groupes de 4 caractères). Cliquez sur **Copier**.
2. Envoyez cet identifiant à l'auteur de Kairn.
3. Il vous renvoie votre code, qui commence par `KRN1.` : collez-le dans **Code d'accès**, puis
   cliquez sur **Activer**.

Kairn vérifie régulièrement que votre accès est toujours valable (au lancement, puis toutes les
heures). Il peut fonctionner 7 jours sans connexion ; au-delà, il demande de se reconnecter à
Internet. Kairn signale à son auteur les activations et les accès refusés (nom, PC, version).

Un code ne marche que sur le PC pour lequel il a été créé : sur un autre PC, demandez-en un nouveau.
Voir aussi [Problèmes d'accès](faq.html#accès).

## Premiers pas

1. **Ajoutez un serveur** : bouton **Ajouter un serveur** (ou le sélecteur de serveur en haut à
   gauche). Donnez son adresse, puis **Détecter** pour trouver sa version. Voir [Serveurs](serveurs.html).
2. **Ajoutez un compte** : page **Comptes**, bouton **Ajouter un compte**. Voir [Comptes](comptes.html).
3. **Connectez-le** : bouton **Connecter** sur sa ligne. Son statut passe à **En ligne**.

Ensuite : lancez des [scripts](scripts.html), récupérez vos kits, ou
[jouez avec un compte](jouer.html) depuis votre propre Minecraft.

Astuce : **Ctrl K** ouvre la recherche rapide de partout (comptes, pages, actions).
